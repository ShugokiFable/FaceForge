# Concept-to-render fidelity ledger

Final comparison: `design/FaceForge-primary-screen-concept.png` against
`qa/render-analyzed-1536x960.png` and `qa/render-analyzed-1100x760.png`.

## Matches

- Preserves the concept's three-column source, analysis, and output workflow.
- Preserves the graphite surface, amber actions, cyan measurements, compact typography, and desktop title bar.
- Shows the analyzed portrait and landmark overlay rather than decorative sample art.
- Keeps the principal controls visible at 1536x960 and uses a contained scrolling output area at 1100x760.
- Preserves the footer privacy state, centered workflow notice, and dominant amber export action.
- Provides photo-first generation, optional template inheritance, editable generated sliders, sculpt handling, exact dependency status, and three explicit package targets.
- Uses a focused settings surface for read-only environment indexing and opt-in provider vision instead of crowding the main workflow.

## Intentional deviations

- No age estimate or fabricated millimeter measurements; the app reports normalized landmark ratios and confidence.
- No "Open RaceMenu" button because 0.11.0 does not launch or automate Skyrim.
- The center diagnostic is a live proportion diagram rather than a cosmetic 3D head.
- Fresh presets tell the user to select race/sex in RaceMenu because JSlot JSON does not carry a standalone target race/sex.
- The output column is denser than the concept because dependency provenance and follower handoff safety are core requirements; it scrolls independently at compact sizes.

Verdict: faithful implementation with safety- and evidence-driven deviations; no blocking visual mismatch.
