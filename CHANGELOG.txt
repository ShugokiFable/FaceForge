FaceForge 0.10.0 - 2026-07-30

That install defines 206 sliders: EFM 83, CME 51, SPG 30, LDD 19, NSK 13, ECE 5, RANs 5. FaceForge wrote 35, all EFM. - Added a slider inventory. FaceForge cannot enumerate slider mods from disk because the names only exist inside RaceMenu at runtime, so it learns them by reading a preset saved from that install. Without one it writes the EFM family alone, which is the only family the plugin index can confirm.
- Established per-family ranges from the five hand-authored reference presets: EFM runs to +/-3 (148 values), while CME, NSK, SPG and RANs run to about +/-1 (132 values, absolute maximum 1.31). A CME value written on the EFM scale would have been three times too strong.

- Integer type selectors are never written. CME_NoseType, CME_EyesType, CME_LipType and ECE_EarShape carry indices that pick a numbered vanilla shape (26, 21, 24, 6 in the supplied preset); writing one as a morph value would silently swap the feature for whichever shape sits at that index.

- Iris size is measured from the refined iris landmarks the model already returns (points 468-477), falling back to the baseline when a mesh arrives without refinement.
- Depth and projection sliders are still not written. A single front photograph contains no depth information, so the fourteen EFM _Depth sliders stay out until a profile view is supported.
- Tooth sliders are still not written, for the same reason: a closed-mouth portrait shows no teeth.
- Likeness strength now defaults to full instead of 70 percent. On top of already conservative measurements it was shrinking every value by a further 30 percent.
- Added a slider inventory panel showing the families found, how many sliders FaceForge writes against how many it can measure in that install, and how to produce the preset it reads.

FaceForge 0.8.0 - 2026-07-30

- Started a full-copy successor from the preserved FaceForge 0.7.0 release, excluding regenerated bin, obj, dist, node_modules, and artifacts.
- Added source correction so imperfect photographs import properly instead of only raising a warning. Until now a tilted, turned, or expressive photo produced a warning and then wrote the contaminated numbers into the preset anyway.
- Tilted sources are now straightened in the image itself and detected a second time. Landmark detection is not rotation invariant, so de-rotating only the landmarks left the model's own error in place; the second pass cut the worst-case slider drift on a 16-degree tilt from 0.581 to 0.154, and the mean from 0.088 to 0.029.
- Any residual tilt is rotated out geometrically, which is exact.
- Head turn and head nod are estimated from landmark depth and un-foreshortened by dividing out the cosine of each angle, up to 32 degrees.
- Beyond 32 degrees the residual is not corrected. Width-driven or height-driven measurements instead lose confidence in proportion to the angle, so an unrecoverable pose fades those features to neutral rather than sculpting a distorted face.
- Left/right differences are removed by mirror-averaging the landmark mesh. EFM sliders are bilateral, so a symmetric input is the only thing the output can represent and averaging both sides beats trusting the nearer one. The seventeen bilateral measurement landmarks are paired from a fixed table; contour points are paired by mutual nearest neighbour for the diagnostic mesh only.
- Added expression handling for fourteen blendshape groups: open mouth, smile, stretched mouth, frown, pursed lips, compressed lips, raised lip, closed or narrowed eyes, widened eyes, moved brows, raised cheeks, wrinkled nose, shifted jaw, and tongue out.
- Each rule fades only the measurements that expression physically moves, in proportion to its strength, with a dead zone for ordinary resting muscle tone. A full smile leaves mouth width at the neutral default instead of building a permanently grinning character.
- Pose residual and expression contamination compound, so a turned head pulling a smile loses more trust than either alone.
- Added a Source correction readout showing tilt, turn, nod, and the number of mirrored landmark pairs, plus a named list of any measurements left at neutral and why.
- Sliders whose measurement was faded are flagged in the output panel: "neutral" when held entirely, or a percentage when partly trusted.
- Retuned the eye and brow expression dead zones so a relaxed face no longer reports a 2 percent expression.
- Added 13 source-correction regressions covering tilt recovery, turn recovery, turn direction, mirror-averaging, asymmetric brows, the unrecoverable-angle cutoff, open mouth, closed eyes, partial fading, slider flagging, a clean neutral source, and compounding.
- Added a rotated-source stage to the browser QA that re-imports the same portrait tilted 16 degrees through the real landmark model and asserts the exported sliders land back on the straight run.
- Verified 39 frontend tests, 50 native assertions, live deployment indexing, rendered browser QA, clean .NET build, single-file gate, and isolated one-file launch.

Runtime status: tool-validated; RaceMenu visual compatibility, in-game likeness, the RaceMenu head bake, Follower Forge NPC construction, and live provider calls remain user-side validation.
